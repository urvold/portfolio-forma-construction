# FORMA — архитектура вашей жизни

Самостоятельный демонстрационный сайт вымышленного архитектурно-строительного бюро. Русский язык, React 19, TypeScript, Vite, React Router, авторские CSS-анимации и SVG. Без backend, аналитики, cookies, CRM и отправки персональных данных.

## Запуск

Требуется Node.js 22.6+ (рекомендуется 24) и npm.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173/portfolio-forma-construction/). Для просмотра с телефона в той же сети используйте адрес Network. В удалённой облачной среде сначала откройте/перенаправьте порт средствами среды: localhost другого компьютера недоступен напрямую.

```sh
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Подготовлена бесплатная публикация через GitHub Pages; workflow `.github/workflows/pages.yml` выполняет тесты, сборку и развёртывание при push в `main`. Пользовательские секреты не требуются.

## Что реализовано

- Главная, каталог, 6 страниц концепций, услуги, 6 подробных страниц услуг, о компании, этапы, контакты, конфигуратор и 404.
- Пять независимых фильтров каталога, их совместное применение, пустое состояние и сброс.
- Пять шагов конфигуратора, четыре различных референса стилей, возврат к шагам, сводка, расчёт и перезапуск. Изображение показывает **стиль**, а не сгенерированную модель выбранного конструктива.
- Интерактивные SVG-планировки: этажи, помещения, площади, легенда, мышь, касание, Tab, Enter и пробел. Это оригинальные демонстрационные схемы, не строительная документация.
- Мобильное меню, анимации появления и наведения, сдержанный параллакс hero, переходы страниц, поддержка reduced motion.
- Локальные WOFF2 с кириллицей, WebP в двух размерах, отложенная загрузка изображений, SEO и Open Graph, семантика и фокус клавиатуры.
- Демоформа содержит только выбор темы и стадии. Нет свободного ввода и персональных полей; нет сетевых запросов, localStorage или отправки данных.

## Структура

- `src/main.tsx` — оболочка, маршруты, редакционные страницы и каталог.
- `src/components/ui.tsx` — типографические и интерфейсные элементы.
- `src/components/Floorplan.tsx` — интерактивная планировка.
- `src/pages/Configurator.tsx` — конфигуратор и открытое описание расчёта.
- `src/data.ts` — централизованные концепции, услуги, этапы.
- `src/tariffs.ts` — условные тарифы и формула. Не коммерческие цены.
- `src/style.css` — дизайн-система, адаптивные правила, motion и reduced motion.
- `public/` — локальные изображения, шрифты, robots и статическая 404.
- `tests/`, `reports/` — проверочные сценарии, JSON, Lighthouse и скриншоты.
- `SOURCES.md` — источники изображений и условия лицензий.

## Проверки

```sh
npm test
npm run build
# В другом терминале запущен npm run dev -- --port 5173
node tests/browser.mjs
```

Браузерный сценарий использует установленный `/usr/bin/chromium`. При другой ОС измените `executablePath` либо используйте Chromium Playwright. Проверяет 20 маршрутов на ширинах 320, 375, 390, 430, 768, 1024, 1440 px, переполнение, ошибки JS, фильтры и пустое состояние, конфигуратор, этажи и комнаты, демоформу. Axe запускается на пяти ключевых маршрутах. `npm test` проверяет 384 комбинации тарифов и рост оценки с площадью/комплектацией.

Для повторного Lighthouse запустите production preview на 4173:

```sh
CHROME_PATH=/usr/bin/chromium npx lighthouse http://localhost:4173/portfolio-forma-construction/ --chrome-flags='--headless --no-sandbox' --output=json --output=html --output-path=reports/lighthouse-mobile
```

Результаты и ограничения описаны в `reports/QA.md`. Автоматические тесты не заменяют реальную проверку iPhone Safari.

## GitHub Pages

Целевой репозиторий: https://github.com/urvold/portfolio-forma-construction . Планируемый адрес сайта: https://urvold.github.io/portfolio-forma-construction/ . Создание репозитория текущим подключением отклонено GitHub (403 Resource not accessible by integration), поэтому эти URL пока не подтверждают публикацию. `base: '/portfolio-forma-construction/'` и HashRouter позволяют открывать вложенные разделы на GitHub Pages без серверного rewrite: `/portfolio-forma-construction/#/projects/nord`. Не заменяйте HashRouter на BrowserRouter без настройки перенаправлений. `public/404.html` предназначен для неизвестных физических путей, React-страница 404 — для неизвестных hash-маршрутов.

Абсолютный `og:image` и canonical настроены на публичный адрес GitHub Pages. При смене домена обновите их в `index.html`. Hash-маршруты удобны для GitHub Pages, но ограничивают отдельную индексацию разделов и отдельные social preview: для коммерческого запуска с полноценным SEO страниц нужен prerender/SSG с обычными URL. Сайт не заявляет, что эти ограничения устранены.

Production-проверка: `FORMA_TEST_URL=http://localhost:4173/portfolio-forma-construction/ npm run test:browser`. Тот же сценарий поддерживает публичный HTTPS URL через эту переменную.
