# FORMA — архитектура вашей жизни

Существующий демонстрационный сайт вымышленного архитектурно-строительного бюро. Русский язык, React 19, TypeScript, Vite, React Router, авторские CSS-анимации и SVG. Без backend, аналитики, cookies, CRM и отправки персональных данных.

## Запуск

Требуется Node.js 22.6+ (рекомендуется 24) и npm.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173/portfolio-forma-construction/). Для просмотра с телефона в той же сети используйте адрес Network. В удалённой облачной среде сначала откройте/перенаправьте порт средствами среды: localhost другого компьютера недоступен напрямую.

```sh
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Базовая версия опубликована бесплатно через GitHub Pages. Доработка от 6 ноября 2026 включает согласованную архитектурную серию, новое мобильное меню, компактную шапку и параметрический конфигуратор; workflow `.github/workflows/pages.yml` выполняет тесты, сборку и развёртывание при push в `main`. Пользовательские секреты не требуются.

## Что реализовано

- Главная, каталог, 6 страниц концепций, услуги, 6 подробных страниц услуг, о компании, этапы, контакты, конфигуратор и 404.
- Пять независимых фильтров каталога, их совместное применение, пустое состояние и сброс.
- Пять шагов конфигуратора, параметрическая SVG-схема, возврат к шагам, сводка, расчёт и перезапуск. Схема меняет стиль, пропорции площади, количество этажей, условное отображение конструктива и степень отделки; это объёмный эскиз, не строительная модель.
- Интерактивные SVG-планировки: этажи, помещения, площади, легенда, мышь, касание, Tab, Enter и пробел. Это оригинальные демонстрационные схемы, не строительная документация.
- Полноэкранное мобильное меню на dialog с фокусом, блокировкой фона, Escape и возвратом прокрутки; компактная шапка без изменения занятого места в потоке; анимации появления и наведения, сдержанный параллакс hero, переходы страниц, поддержка reduced motion.
- Локальные WOFF2 с кириллицей, WebP в трёх размерах, отложенная загрузка изображений, SEO и Open Graph, семантика и фокус клавиатуры.
- Демоформа содержит только выбор темы и стадии. Нет свободного ввода и персональных полей; нет сетевых запросов, localStorage или отправки данных.

## Структура

- `src/main.tsx` — оболочка, маршруты, редакционные страницы и каталог.
- `src/components/ui.tsx` — типографические и интерфейсные элементы.
- `src/components/Floorplan.tsx`, `src/plans.ts` — интерактивная планировка и согласованные площади/геометрия.
- `src/components/Header.tsx` — компактная шапка и доступный модальный диалог навигации.
- `src/components/HouseVisual.tsx` — собственная параметрическая SVG-схема для конфигуратора.
- `src/pages/Configurator.tsx` — конфигуратор и открытое описание расчёта.
- `src/data.ts` — централизованные концепции, услуги, этапы.
- `src/tariffs.ts` — условные тарифы и формула. Не коммерческие цены.
- `src/style.css` — дизайн-система, адаптивные правила, motion и reduced motion.
- `public/` — локальные изображения, шрифты, robots и статическая 404.
- `tests/`, `reports/` — проверочные сценарии, JSON, Lighthouse и скриншоты.
- `SOURCES.md` — источники изображений и условия лицензий.

## Проверки

```sh
npm test
npm run build
# В другом терминале запущен npm run preview -- --port 4173
npm run test:browser
```

Браузерный сценарий использует установленный `/usr/bin/chromium`. При другой ОС измените `executablePath` либо используйте Chromium Playwright. Проверяет 20 маршрутов на ширинах 320, 375, 390, 430, 768, 1024, 1440 px, переполнение, ошибки JS, фильтры и пустое состояние, конфигуратор, этажи и комнаты, демоформу. Актуальный финальный сценарий — tests/final-audit.mjs: axe на шести ключевых страницах, 54 помещения на 9 этажных схемах, все фильтры, 8 полных подборов, мобильный диалог, focus trap, сохранение прокрутки и сенсорный контекст. `npm test` проверяет 384 комбинации тарифов и рост оценки с площадью/комплектацией.

Для повторного Lighthouse запустите production preview на 4173:

```sh
CHROME_PATH=/usr/bin/chromium npx lighthouse http://localhost:4173/portfolio-forma-construction/ --chrome-flags='--headless --no-sandbox' --output=json --output=html --output-path=reports/lighthouse-mobile
```

Актуальные результаты доработки и ограничения описаны в `reports/final-refinement/QA.md`; `reports/QA.md` и корневые Lighthouse-файлы сохраняют историю первоначального запуска. Автоматические тесты не заменяют реальную проверку iPhone Safari.

## GitHub Pages

Репозиторий: https://github.com/urvold/portfolio-forma-construction . Сайт: https://urvold.github.io/portfolio-forma-construction/ . Pages включён владельцем; исходники загружены, workflow успешно выполнил сборку и публикацию. HTTPS включён. Повторный браузерный аудит опубликованного сайта прошёл. `base: '/portfolio-forma-construction/'` и HashRouter позволяют открывать вложенные разделы на GitHub Pages без серверного rewrite: `/portfolio-forma-construction/#/projects/nord`. Не заменяйте HashRouter на BrowserRouter без настройки перенаправлений. `public/404.html` предназначен для неизвестных физических путей, React-страница 404 — для неизвестных hash-маршрутов.

Абсолютный `og:image` и canonical настроены на публичный адрес GitHub Pages. При смене домена обновите их в `index.html`. Hash-маршруты удобны для GitHub Pages, но ограничивают отдельную индексацию разделов и отдельные social preview: для коммерческого запуска с полноценным SEO страниц нужен prerender/SSG с обычными URL. Сайт не заявляет, что эти ограничения устранены.

Production-проверка: `FORMA_TEST_URL=http://localhost:4173/portfolio-forma-construction/ npm run test:browser`. Тот же сценарий поддерживает публичный HTTPS URL через эту переменную.

Проверка публичных ресурсов: `python tests/public-assets.py` (стандартная библиотека Python). Результаты: `reports/public-assets.json`, `reports/browser.json`, `reports/DEPLOYMENT.md`.

## Визуальная серия и происхождение

Шесть концепций теперь имеют единую серию AI-визуализаций с согласованной этажностью и палитрой. Это не фотографии реализованных зданий. Общие интерьерные референсы удалены из галерей домов; галерея содержит фрагмент того же исходного вида и собственную палитру материалов. См. SOURCES.md и public/images/sources.json.

Локальная production-версия: `npm run build`, `npm run preview -- --port 4173`, затем http://localhost:4173/portfolio-forma-construction/ . Отправка изменений в main автоматически обновляет сайт через GitHub Actions. Публикация этой доработки подтверждена пользователем.
