# Изображения FORMA: происхождение и использование

## Архитектурная серия, 6 ноября 2026

Шесть основных изображений созданы инструментом OpenAI Image Generation специально для вымышленных концепций FORMA. Это **AI-визуализации, а не фотографии построенных объектов**. Они не заимствованы с сайтов архитектурных бюро и не выдаются за реально реализованные дома. Промпты задавали оригинальные объёмы, этажность, стили, материалы и общую художественную подачу. Площадь — заданный параметр концепции, не обмер и не результат измерения изображения.

| Файл | Концепция | Параметры визуализации |
|---|---|---|
| hero | Горизонт | 218 м², один этаж, горизонтальный павильон с плоской крышей, камень, дерево, панорамное остекление |
| nord | Норд | 156 м², два полноценных этажа, современный скандинавский дом, светлая древесина, фальцевая кровля |
| barn | Поле | 112 м², один этаж без антресоли, современный барнхаус, дерево, тёмная двускатная кровля |
| classic | Равновесие | 286 м², два этажа, современная классика, симметрия, светлый камень, плоский парапет |
| forest | Роща | 178 м², один этаж, современный минимализм, внутренний двор, камень и деревянные экраны |
| stone | Патио | 242 м², два этажа, смещённые плоские объёмы, каменный низ, деревянный верх |

Условия использования результатов генерации: https://openai.com/policies/terms-of-use/ (раздел Content). Это происхождение результатов генерации, не заявление об исключительности или регистрации авторских прав. Идентификаторы исходных результатов и контрольные суммы WebP зафиксированы в `public/images/sources.json`. Оригиналы генерации сохранены в рабочей среде `/workspace/generated_images`; WebP-копии входят в исходники проекта.

Для каждого дома используется один исходный архитектурный вид. В галерее показывается **фрагмент того же вида**, явно подписанный как фрагмент; интерьер другого здания под названием проекта не показывается. Палитра материалов — собственные CSS-образцы оттенков, не сертификаты материалов и не фотографии фасада.

## Редакционные интерьерные референсы

`interior`, `detail` — независимый интерьерный референс для страниц философии/услуг; `detail` — кадрирование того же источника. Он не относится к галереям домов и не заявлен как работа FORMA.

Сохранён локально, преобразован в WebP. Старые фотографии красного домика, заснеженного шале и случайных вилл заменены, их прежние URL больше не являются источниками текущих архитектурных файлов.

## Шрифты и графика

- Manrope, Mikhail Sharanda, SIL Open Font License 1.1. Локальные WOFF2 с кириллицей, лицензия `public/fonts/OFL.txt`, источник https://fonts.google.com/specimen/Manrope .
- Lucide: единый набор SVG-иконок, ISC, лицензия в пакете lucide-react.
- Интерактивные планировки и параметрическая объёмная схема конфигуратора созданы для проекта в SVG. Не строительная документация.
- Georgia — системная акцентная гарнитура, не распространяется вместе с проектом.

Все адаптивные версии (`-mobile`, `-small`, основная) производны от соответствующего единственного исходника, без подмены здания между размерами экрана.
