## Что исправлено

- Заменены все шесть основных архитектурных изображений согласованной серией AI-визуализаций, созданной для концепций. «Горизонт», «Поле», «Роща» — одноэтажные; «Норд», «Равновесие», «Патио» — двухэтажные. Изображения визуально проверены. Площадь — заданный параметр концепции, не обмер по картинке.
- Удалены чужие интерьерные фотографии из галерей проектов. Каждая галерея использует фрагмент того же изображения и оригинальную палитру оттенков. Интерьерный референс сохранён только в редакционных материалах/услугах.
- Происхождение и условия использования описаны в `SOURCES.md`, идентификаторы генераций и SHA-256 — `public/images/sources.json`. Фото не выдаются за работы бюро; AI-визуализации подписаны на страницах проектов, каталоге, hero и в футере.
- Мобильное меню — нативный полноэкранный dialog с непрозрачным фоном, SVG Lucide, блокировкой фоновой прокрутки, замкнутым Tab/Shift+Tab, Escape, возвратом фокуса. При закрытии без перехода восстанавливает положение страницы; при переходе открывает начало целевого раздела. При переходе на desktop закрывается и разблокирует страницу.
- Шапка плавно уменьшается с 78 до 56 px на мобильном (плюс safe area); зарезервированное место в потоке сохраняется, скачка страницы нет. На desktop 100 → 72 px. Учтены env(safe-area-inset-top/bottom), viewport-fit=cover и reduced motion.
- Удалён знак ®. Пересмотрены размеры и переносы заголовков, отступы на страницах услуг, каталога, проектов, контактов и 404; исправлен слишком широкий заголовок 404 на 320 px. Основные тексты на мобильном остаются 16–18 px.
- Конфигуратор больше не показывает статичное фото, противоречащее этажности. Собственная параметрическая SVG-схема изменяет стиль крыши/фасада, число этажей, пропорции в зависимости от площади, условную фактуру конструктива и степень отделки. Это явно обозначенная объёмная схема, не строительная или фотореалистичная модель.
- У планировок точно согласованы суммы площадей, геометрические доли и легенда; планы этажей различаются. Терраса больше не учитывается как внутренняя площадь. Все помещения выбираются SVG, списком, касанием, Enter и пробелом.
- Добавлены версии изображений 480/800/1536 px, корректные sizes, локальные WOFF2, приоритет hero. Ни backend, ни сбор персональных данных не добавлялись.

## Визуальный аудит и ограничения

Просмотрены новая серия всех домов, скриншоты каталога и главной, мобильного меню, услуги на 320 px, мобильного конфигуратора, компактной шапки, одно-/двухэтажных объёмов. Сохранены скриншоты каждого из восьми сочетаний стиль/этажность. Визуализации домов согласованы по изображённой этажности и архитектурному характеру; площади и материалы не являются подтверждёнными характеристиками построенных объектов.

Реального iPhone/Safari и WebKit в проверке не было. Использованы Chromium на заданных ширинах и сенсорный контекст. CSS safe-area и стабильная высота проверены по реализации и в Chromium; это не заявление о проверке устройства iPhone. Перед коммерческим запуском рекомендуется реальный iPhone.

Новая версия проверена локально под `/portfolio-forma-construction/`, HashRouter сохранён для GitHub Pages. Публичный HTTPS проверен только у прежней версии. Workflow main автоматически публикует изменения. Пользователь отдельно подтвердил публикацию после данного локального аудита.

## Как просмотреть

```sh
cd /workspace/portfolio-forma-construction
npm ci
npm run build
npm run preview -- --port 4173
```

Открыть `http://localhost:4173/portfolio-forma-construction/`. В облачной среде нужен просмотр или перенаправление порта 4173 средствами этой среды.

```sh
npm test
npm run test:browser
node tests/motion-audit.mjs
FORMA_TEST_URL=http://localhost:4173/portfolio-forma-construction/ FORMA_REPORT_DIR=reports/final-refinement python tests/public-assets.py
```
