# Итоговый аудит FORMA

Дата: 2 ноября 2026. Проект локальный; публикации и создания GitHub-репозитория не было.

## Сборка и функции

- `npm run build`: TypeScript и production Vite build проходят.
- `npm test`: проверки всех 384 сочетаний тарифов, положительных диапазонов и роста расчёта с площадью/комплектацией проходят.
- Chromium / Playwright: 20 маршрутов (включая неизвестный hash URL), 7 ширин: 320, 375, 390, 430, 768, 1024, 1440. Всего 140 комбинаций URL/ширины. Горизонтальное переполнение не обнаружено.
- Ошибок JavaScript и HTTP-ошибок загрузки ресурсов в сценарии не обнаружено.
- Проходят фильтрация по стилю, сочетание с этажностью, пустое состояние, сброс, пять шагов конфигуратора, результат, перезапуск, переключение этажа, выбор комнаты, Enter на SVG, закрытие мобильного меню по Escape, демоформа.
- Отдельный Chromium-контекст 390×844 с `isMobile` и `hasTouch`: выбор стиля и следующий шаг по tap проходят.
- Axe WCAG 2 A/AA и 2.1 AA: ноль нарушений на главной, каталоге, конфигураторе, странице двухэтажного проекта и контактах. Это автоматическая, не исчерпывающая сертификация доступности.
- Визуально просмотрены скриншоты главной на desktop/mobile, конфигуратора и исходные фотографии. Неподходящие референсы заменены. Фотографии не выдаются за работы FORMA.

Подробности: `browser.json`. Воспроизводимый сценарий: `tests/browser.mjs`.

Отчёты: `lighthouse-mobile.report.html/json`, `lighthouse-desktop.report.html/json`. В предыдущем мобильном замере после оптимизации Performance был 95; оценки меняются между запусками. Это измерения локального стенда, не гарантия показателей будущего хостинга. SEO-оценка относится к главной и базовым техническим проверкам, а не к полноценной индексации hash-разделов.

Исправлены найденные проблемы: контраст второстепенных подписей на сером фоне, локальные WOFF2 вместо тяжёлых TTF, robots.txt, высокий приоритет hero, доступное имя логотипа. Изображения WebP имеют адаптивные варианты, шрифты локальные, приложение не обращается к сторонним сервисам при обычном использовании.

## Ограничения

- Реальные Safari/iPhone и WebKit не тестировались. Проверены Chromium, несколько viewport и сенсорная эмуляция. Это не проверка Safari. Перед коммерческой публикацией желательна ручная проверка на iPhone.
- Применён HashRouter для надёжного открытия разделов на GitHub Pages. Отдельные разделы не имеют независимого серверного HTML для поисковых и социальных роботов. Для полноценных SEO URL нужен SSG/prerender и обычная маршрутизация.
- До публикации нужно задать абсолютный OG image и canonical под окончательный URL. Относительный локальный OG image — подготовительный вариант.
- Конфигуратор визуализирует выбранный стиль референсом, не моделирует конструктив и не обещает точное соответствие фото выбранной площади/этажности. Все параметры и условная цена отражаются в сводке.
- Планировки — оригинальные схемы интерфейса, не строительные чертежи. Галереи — референсы архитектуры и интерьера.
- Бренд, проекты, цены и услуги концептуальны. Демо не собирает персональные данные, ничего не отправляет и не хранит.

## Подготовка к GitHub Pages

После отдельного подтверждения пользователя базовый путь изменён на `/portfolio-forma-construction/`. Повторно успешно выполнены `npm test`, `npm run build` и полный браузерный сценарий для production URL `http://localhost:4173/portfolio-forma-construction/`. Все 140 сочетаний маршрутов и ширин, фильтры, конфигуратор, планировки, клавиатура, touch и axe проходят, HTTP-ошибок загрузки изображений/шрифтов нет.

Добавлен workflow `.github/workflows/pages.yml`: Node 24, npm ci, тесты, production build, официальный Pages artifact/deploy, запуск при push в main. В workflow не нужны пользовательские секреты. Абсолютные OG image и canonical настроены под планируемый Pages URL. `.env`, ключи, локальная конфигурация среды, node_modules и dist исключены из Git.

Создать удалённый репозиторий не удалось: GitHub вернул GraphQL `Resource not accessible by integration (createRepository)` и REST HTTP 403 `Resource not accessible by integration`. Репозиторий и Pages не созданы; публичный HTTPS ещё не проверен. Это ограничение прав подключённой интеграции GitHub, не ошибка сборки сайта. Для продолжения нужен пустой публичный репозиторий urvold/portfolio-forma-construction, доступный текущему подключению. Другие репозитории не изменялись.
